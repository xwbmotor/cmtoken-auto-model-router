# 分类器训练数据与模型

`raw.jsonl` 是仓库保留的训练输入。`model/` 存放分类器镜像构建时使用的文件：

- `task.joblib`：任务类型模型。
- `tier.joblib`：难度档位模型。
- `complexity.joblib`：复杂度模型。
- `meta.json`：模型元数据。
- `heldout.jsonl`：保留的评测输入。

普通安装使用交付包中的分类器镜像，不需要重新训练或编辑这些文件。自行构建分类器镜像时须保留模型文件，并使用锁定的依赖版本；模型文件只能从可信来源取得。

训练和评测记录用于解释模型来源，不代表所有真实业务的分类准确率。新采集的对话、标注或凭证不得作为普通调试文件直接提交。开发与验证方法见 [开发指南](../../docs/开发指南.md)。
