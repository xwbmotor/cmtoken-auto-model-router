AUTO ROUTING · 模型广场

一个 model 名，自动选对模型

调用时把 model 填成 auto，路由器按任务类型与难度自动挑最合适的模型：简单任务用便宜的快模型，复杂任务用最强模型——省钱、省心、不掉质量。

三步接入

① 拿到接入密钥向管理员申请 ROUTER_ACCESS_KEY（业务应用调用本路由用）。
② 改一个参数把请求里的 model 从具体模型名换成 auto：POST /v1/chat/completions { "model": "auto", "messages": [...] }
③ 完成其余参数（messages/tools/stream/response_format）原样支持，OpenAI 兼容，业务代码零改动。

auto 是怎么选模型的

  1. 识别任务：按请求内容把任务分为通用/代码/推理/抽取/创意/轻量六类，并评估难度（简单/均衡/复杂）。
  2. 查跑分：每个模型在六个任务维度上有实测校准的质量分（eval gate 实测，非宣传数字）。
  3. 综合打分：质量分为主，叠加成本与时延敏感度、质量底线过滤、自建优先偏好，选综合最优。
  4. 自动兜底：首选模型调用失败自动切换备选；新模型先试点观察，跑够真实流量才全面接管。
💡 管理员可用「成本档位」一键切换省钱/均衡/质量/顶配——档位是成本带，不是简单上限 🔒 每笔路由决策落盘可查（任务类型/候选得分/最终选择），响应头 x-router-* 透明可审计
