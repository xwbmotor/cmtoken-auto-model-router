- [制作安装包](offline/BUILD.md)：标准配置或自定义配置的打包方法。
- [现有服务运维](../docs/Ubuntu生产部署.md)：停止顺序、升级与回滚。

Python 安装工具保留用于已有交付流程，见 [Python 工具说明](python-install.md)。
