auto-model-router · 三层路由架构

规则分类（零成本）→ 语义复核（条件触发）→ 加权评分（动态打分）

三层路由

  • • ① 规则分类：正则 + 6 信号累加，零模型调用
  • • ② 语义复核：仅 confidence < 0.7 触发
  • • ③ 加权评分：硬性过滤 + 打分排序
  • • 三层输出统一落进决策日志

动态输入

  • • livePenalty：EWMA 时延 + 连续失败实时扣分
  • • budgetPressure：超支时放大成本权重
  • • 硬性过滤：disabled / 熔断 / 超上下文 / 缺能力
  • • 评分策略可插拔，预留 learned 接口

决策日志

  • • 记录 signals / semantic / candidates / selectedModel
  • • 是未来 learned 评分策略的训练原料
  • • JSONL 按天分文件，16MB 轮转，保留 14 份
  • • 消息默认脱敏，可 opt-in 存全文
