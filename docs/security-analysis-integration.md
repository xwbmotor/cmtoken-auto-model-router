# 纯分析服务接入与数据飞轮配合清单

本次安全整改将纯分析服务与正常转发分开。正常转发的模型调用、SSE、用量结算、反馈和对账记录继续保留；不为纯分析要求清空既有生产数据，也不自动关闭已明确配置的训练采集。纯分析服务不接管业务请求，不调用生成式模型，不写入原始请求正文。

现有代码核查基线为 `0.14.10 / e9a7b41`。以下清单说明工程接入和数据使用安排，不表示相关平台配置、样本审批或训练已经完成。

## 数据飞轮需要保留什么

需要持续保留“输入特征—路由建议—实际执行—质量反馈”的关联。只留下建议模型和请求数量，可以观察路由分布，但不足以判断路由是否选得更好。训练还需要有代表性的样本、可靠标签及独立验证集，采集量本身不能保证效果提升。

| 数据 | 用途 | 建议保存位置与处理方式 |
| --- | --- | --- |
| 分析事件ID、业务关联映射 | 将路由建议与真实调用、反馈关联 | 分析服务返回随机事件ID；中台保存其与业务请求的映射，分析服务不接收用户身份或原业务Key。映射权限和期限单列。 |
| 策略/模型版本、候选范围、任务类别、难度、置信度、Token估算、候选评分与拒绝原因 | 发现分布变化、低置信样本、策略差异和候选覆盖问题 | 保存约定的结构化结果；拒绝原因用固定代码，不把用户原文或模型自由解释混入结果。 |
| 实际执行模型及版本、回退轨迹、usage、费用、时延和错误类别 | 对比建议与实际运行，优化成本、容量与时延 | 由中台真实业务链回传到受控分析数据集；纯分析服务没有实际调用，不能自行生成这些结果。 |
| 评分、点赞/点踩、业务任务是否完成、评审来源及规则版本 | 建立质量反馈，筛选错误案例 | 由业务、中台和评估人员提供。HTTP成功、自动分类标签、模型自评不能直接当作人工真值。文字评论单独脱敏，不默认进入无正文数据集。 |
| 经批准的输入样本及必要上下文 | 重放、人工标注、语义分类器训练、困难样本分析 | 放在中台或批准的训练环境样本库，采用限量抽样、分级访问、期限和删除机制；纯分析虚拟机不保存副本。样本ID不是自动获取原文的凭证。 |
| 经批准的回答样本及评价依据 | 回答质量复核、模型间对比 | 与输入样本配对受控保存。评分程序需要题目和回答；只有评分数字不能重新核查其依据。 |
| 采样、拒绝、丢弃和关联失败计数，采样规则版本 | 识别过滤偏差和样本缺失 | 中台与采集平台共同记录。不能只统计成功到达分析服务的请求。 |

### 与现有训练代码的关系

- `scripts/train_classifier.py` 读取文本及 `task/tier/complexity` 标签，训练语义分类器。完全没有可用文本样本时，无法用新业务样本更新这条训练链。
- `scripts/mine-decisions.py` 关联决策、反馈和Judge记录，可在没有正文时汇总部分运行与评分信息；人工审阅候选没有题目时不能继续做内容判断。该脚本输出的是待审候选，不是自动合格的训练集。
- `scripts/prepare-routing-learning.mjs` 和 `src/learning-data.mjs` 当前需要完整、符合约定的请求来核对输入哈希并提取24维数值特征。产生的 `fit.json` 和 `blind.json` 不含原始请求，后续拟合可以使用特征和评估结果。准备步骤可以在允许访问样本的受控环境执行；纯分析接口结果不能直接替代现有训练输入协议。
- `src/learned-routing.mjs` 的离线学习要求分组训练/验证/测试数据和多候选结果。只有线上最终选中的一个模型结果，会缺少其他候选在同一任务上的表现；需另行组织获准的离线对比或实验，不能补造未调用模型的结果。
- 现有Judge评估会使用请求和回答并调用模型。纯分析部署不运行这项任务；如需继续产出Judge分数，应在获准的业务或评估环境运行，明确允许的模型及数据范围。
- `src/operations-evidence.mjs` 的运行监测主要使用模型、时延、错误等结构化数据，不依赖正文。取消正文默认暴露不应阻断这类监测。

## 需要中台配合的事项

| 事项 | 交付内容 | 联调检查 |
| --- | --- | --- |
| 请求筛选和异步复制 | 确认auto场景判定、允许采集字段、独立队列及满额丢弃规则 | 非auto不复制；分析断链、超时、限流不影响真实响应；不将原业务Key带到分析服务。 |
| 敏感内容处理 | 数据类别、删除/替换/跳过规则、规则版本和测试样例 | 在离开中台前处理；不能仅凭“已被算法处理”认定已脱敏。 |
| 建立事件关联 | 保存业务请求与分析事件ID映射，并约定去重及迟到处理 | 能关联实际模型、usage、费用、时延和反馈；不能把建议模型写成实际执行模型。 |
| 保存过滤统计 | 采集总数、入选/拒绝/丢弃数和原因，采样比例及规则版本 | 可计算覆盖率；队列丢弃和隐私过滤不被误记为模型失败。 |
| 提供真实结果 | 真实模型及版本、调用结果、时延、usage、成本、业务反馈 | 区分传输成功和任务成功；明确缺失值，避免默认填写成功或零成本。 |
| 受控样本通道 | 若获批，建设限量样本库和人工审核/训练取数流程 | 样本与标签、版本一致；输入修改后重新生成哈希，不复用修改前的评测结果。 |

## 需要运维与网络配合的事项

| 事项 | 交付内容 | 联调检查 |
| --- | --- | --- |
| 独立部署 | 独立进程/容器、账号和配置，不能把纯分析入口直接并入现有转发入口 | 纯分析实例无法访问生产对账目录、模型凭据及无关管理接口；原转发实例继续正常服务。 |
| 加密传输 | VIP入口证书、TLS及后端监听限制；大数据接入加密方案 | 非批准来源和后端绕行被拒绝；证书校验失败时连接失败。 |
| 来源与出站限制 | 中台来源白名单、必要端口、必要数据平台出站 | 纯分析实例不能访问模型推理端点、生产数据库和其他无关业务。 |
| 凭据管理 | 独立分析凭据的安全交付、轮换、撤销和访问权限 | 分析凭据不能管理系统；管理凭据不能替代分析凭据；不记录凭据原值。 |
| 主机与日志配置 | 4A纳管、实名操作、代理/容器日志字段、调试转储和备份策略 | 应用不写正文之外，还需确认代理、转储、备份没有意外收集正文。 |
| 主备与版本 | 相同安装包、配置及网络规则，明确回滚步骤 | VIP切换后鉴权、TLS和访问限制仍生效；安装包与测试版本一致。 |

## 需要大数据平台配合的事项

| 事项 | 交付内容 | 联调检查 |
| --- | --- | --- |
| 分析数据集 | 固定字段字典，关联建议、实际执行与反馈 | 请求ID可去重，迟到结果可关联，缺失和孤立反馈有统计；禁止自由正文混入元数据字段。 |
| 权限和期限 | 分离写入、查询、导出、管理账号；明确各数据集保存期限 | 业务写入账号不能修改审计历史，未授权人员不能查询或导出。 |
| 审计留存 | 安全审计不少于六个月，集中采集、防改删及缺失告警 | 验证实际保留策略及改删拒绝；不将六个月要求套用到Prompt原文。 |
| 样本与训练批次 | 若获批，单独管理样本库、评估矩阵、特征文件和标签来源 | 训练/验证/测试按分组隔离；样本撤回或到期后，落实源样本及衍生批次处置。 |

## 会影响迭代能力的限制及待决定事项

| 限制 | 对数据飞轮的影响 | 建议处理 |
| --- | --- | --- |
| 所有环境都禁止保存任何输入文本 | 无法持续积累业务语义训练样本，不能重放或复核困难案例 | 讨论允许中台受控域保存获批的少量脱敏样本；虚拟机仍不保存正文。若不获批，明确本期只能做结构化观测及有限调参。 |
| 不保留回答，也不允许任何质量评估任务 | 无法复核回答质量；成本和时延改善可能掩盖质量下降 | 争取受控样本评估，或提供可追溯的业务完成指标/人工反馈。纯分析实例不承担Judge调用。 |
| 禁止任何事件关联或只留下汇总数 | 路由建议无法关联实际调用和反馈，难以学习“什么请求适合哪个模型” | 使用随机分析ID，映射留在中台受控域；无需给分析实例真实用户身份。 |
| 首期只接受少量文本，剔除历史、工具与多模态 | 工具需求、长上下文和多模态路由无法被完整评估，当前采样集不代表全部业务 | 首期标明覆盖范围；扩展前批准所需结构特征或受控样本，不宣称已验证被排除场景。 |
| 敏感场景全部跳过 | 可能系统性缺少金融、医疗等困难场景，训练分布偏向容易请求 | 保留跳过类别及数量；如业务确需覆盖，另建批准的匿名化或人工构造评估集，单列来源。 |
| 不允许离线多模型对比或任何探索调用 | 只能看到现行策略所选模型结果，不能可靠比较未选候选 | 申请限量、限预算、受控数据的离线共同候选评估。未获批前不自动增加模型调用。 |
| 样本期限短于反馈到达和训练周期 | 结果关联失败、无法复核标签、批次不完整 | 由业务与安全方共同确定必要期限，区分样本、结构化结果、映射和审计，不统一无限期保存。 |

以上冲突不通过隐藏采集或把正文改名为“元数据”解决。此次修复不删除历史数据，不将原文采集开关自动打开，也不保证仅凭无正文结果就能提升语义模型。需要审批的采样范围、保留期限、评估模型调用和受控样本库，由业务与安全团队明确后再接入。

## 联调完成条件

1. 正常转发的非流式和SSE调用、usage、费用、反馈及对账回归通过。
2. 纯分析实例的错误凭据、未知字段、超限、慢读、拥塞及断链测试通过；合成正文不进入日志、转发持久化或模型请求。
3. 使用合成事件贯通“分析建议→中台实际结果→反馈→分析数据集”，验证关联、去重、迟到和缺失统计。该项必须在集成环境完成，仓库单元测试不能替代。
4. 授权的全文采集/导出仍可用于独立受控训练流程，默认查询不暴露正文；模拟数据可完成现有准备、训练和盲测协议校验。真实模型改善需另以独立样本验证。
