# 配置与评测输入

| 文件 | 用途 |
|---|---|
| `router.json` | 仓库默认的中台地址、模型池和路由参数；标准安装包使用这份配置 |
| `benchmark-data.json`、`.example` | 评分导入数据及格式示例 |
| `eval-gate.json` | 评测题库 |
| `subtask-eval.json`、`subtask-eval-extra.json` | 细分类任务评测输入 |

生产实例会使用自己的配置副本。修改仓库文件不会自动改变正在运行的服务；安装后通过管理页面编辑、检查影响并发布。

部署前确认中台地址、模型 ID、权限和价格适用于目标环境。已有评分与题库不能直接证明新环境中的模型质量。业务 key、管理凭证和内部 token 不应填进这些仓库文件。

安装步骤见 [安装说明](../deployment/offline/README.md)，参数行为见 [路由设计](../docs/路由设计说明.md)。
